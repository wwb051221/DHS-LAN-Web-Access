# 局域网网页访问插件 · 安装与使用说明

> 项目：https://github.com/wwb051221/DHS-LAN-Web-Access
> 插件包名：`@local/dsh-lan-access` ｜ 版本：1.0.0 ｜ 适用：DeepSeek Harness 桌面版（Windows）

本插件让**同一局域网内的手机、平板、其他电脑**通过一个端口打开 DeepSeek Harness 的网页界面，并使用**网站式密码登录**。无需复制令牌链接，也不会把进程启动令牌暴露给访客。

---

## 1. 功能一览

| 能力 | 说明 |
|---|---|
| 局域网访问 | 在 `0.0.0.0:8848`（可配置）开启 HTTP/WebSocket 反向代理，转发到本机网页服务 |
| 密码登录 | 其他设备打开端口先看到登录页，输入访问密码后进入完整网页界面 |
| 自定义密码 | 面板中设置自己的密码（6–128 位），或随机重新生成 |
| 会话吊销 | 修改/重置密码后，之前已登录的设备立即失效，需用新密码重新登录 |
| 防暴力破解 | 密码错误 1 分钟内满 5 次锁定 1 分钟；密码比对为恒定时间比较 |
| 本机面板 | `/_lan-access` 显示局域网地址、当前密码（可显示/复制）、密码管理 |

---

## 2. 工作原理（简述）

DeepSeek Harness 的内置网页服务只监听 `127.0.0.1`，且带有 Host/Origin 防护，因此局域网设备无法直接访问。本插件：

1. 另起一个监听器（默认 `0.0.0.0:8848`），把 HTTP 与 WebSocket 流量反向代理到本机网页服务；
2. 转发时把 `Host` / `Origin` / `Referer` 重写为回环地址，通过 DSH 的请求防护；
3. 访客在登录页输入正确密码后，**由插件在服务端**完成 DSH 的启动令牌交换，只把签名会话 Cookie 交给浏览器——令牌本身从不发给访客；
4. 密码修改时记录「会话截止时间」，代理层会剔除早于该时间的会话 Cookie，实现旧设备强制下线。

---

## 3. 系统要求

- DeepSeek Harness 桌面版（在本机 0.2.1-rc.3 / Electron 44.7.0 / Windows 上验证）
- 其他设备与本机处于**同一局域网**（同一路由器 / Wi-Fi）
- 默认使用 TCP 8848 端口（可改）

## 4. 安装

### 4.1 获取并解压

从 [Releases](https://github.com/wwb051221/DHS-LAN-Web-Access/releases) 下载 `dsh-lan-access-v1.0.0.zip`，解压到任意固定位置（建议保留在本机，例如 `D:\dsh-plugins\dsh-lan-access`），记住该文件夹的**绝对路径**。不要删除或移动它，插件从该目录加载。

也可以直接使用仓库根目录（克隆或下载源码）。

### 4.2 通过网页界面安装

1. 打开 DeepSeek Harness，点击左侧边栏的 **Plugins（插件）** 页面；
2. 点击 **Add plugin（添加插件）**；
3. 在输入框中填入解压后的文件夹**绝对路径**，例如：
   `D:\dsh-plugins\dsh-lan-access`
4. 点击 **Install（安装）**，等待安装完成；
5. 确认 **Installed plugins（已安装插件）** 中出现 `局域网网页访问`（LAN Web Access），且开关处于开启状态。

> 也可以让 Agent 代为安装：把解压后的文件夹路径发给 Agent，说「安装这个插件」。

安装后插件立即生效，无需重启程序（若未生效可重启 DeepSeek Harness）。

### 4.3 卸载

- 在 Plugins 页面找到本插件 → 详情页 → **Remove（卸载）**；或仅关闭开关停用。
- 卸载后可删除插件文件夹与密码文件 `%USERPROFILE%\.dsh\.dsh-lan-access.json`。

## 5. 使用

### 5.1 打开管理面板（本机）

浏览器打开：

```
http://127.0.0.1:<DSH网页端口>/_lan-access
```

其中 `<DSH网页端口>` 是当前 DeepSeek Harness 网页界面的端口（每次启动可能变化，例如 49840、60874 等）。获取方法：向 Agent 询问「当前 DSH 网页端口」，或查看环境变量 `DSH_WEB_URL`。

面板需要密码登录。面板内容：
- 本机各网络接口的局域网地址（如 `192.168.1.124 (WLAN)`）及可访问网址；
- 当前访问密码（默认隐藏，可显示/复制）；
- 自定义密码、随机重新生成；
- 防火墙放行命令提示。

### 5.2 首次密码

插件首次运行会自动生成一个 12 位随机密码，保存在：

```
%USERPROFILE%\.dsh\.dsh-lan-access.json
```

（若设置了 `DSH_HOME`，则位于 `%DSH_HOME%\.dsh-lan-access.json`）

登录面板后可在面板中查看并改成自己好记的密码。

### 5.3 其他设备访问

1. 在面板中找到与手机/电脑**同一网络**的接口地址（通常是 WLAN / 以太网；蓝牙共享、WSL 等接口其他设备通常无法访问）；
2. 在其他设备浏览器打开 `http://<该地址>:8848`；
3. 输入访问密码登录，之后可正常使用完整网页界面，浏览器会记住登录状态。

### 5.4 修改密码

面板中「访问密码」区域：

- **保存自定义密码**：输入当前密码 + 新密码（两次确认），6–128 个字符；
- **随机重新生成**：只输入当前密码，生成新的 12 位随机密码。

两种方式都会**立即让之前已登录的设备失效**，本机面板会话不受影响。

### 5.5 防火墙

若其他设备能 ping 通但打不开网页，通常是 Windows 防火墙拦截。以管理员身份运行 PowerShell：

```powershell
netsh advfirewall firewall add rule name="DSH LAN Access" dir=in action=allow protocol=TCP localport=8848
```

## 6. 配置项

| 字段 | 默认值 | 说明 |
|---|---|---|
| `host` | `0.0.0.0` | 局域网监听地址；一般保持默认（监听所有网卡） |
| `port` | `8848` | 局域网端口；`0` 表示由系统随机分配 |
| `password` | 无 | 固定访问密码；设置后优先于自动生成的密码，面板将显示「由配置指定」 |

修改方式：编辑 profile 的补丁文件 `%USERPROFILE%\.dsh\profiles\desktop\cordis.patch.yml` 增加覆盖项（id 为 `dsh-lan-access`），或让 Agent 代为修改；修改后需要重启 DeepSeek Harness 以重新加载监听端口。

示例（把端口改为 9000、固定密码）：

```yaml
- id: dsh-lan-access
  name: '@local/dsh-lan-access'
  config:
    host: 0.0.0.0
    port: 9000
    password: 我的访问密码
```

> 提示：端口被占用时插件启动会失败（可在插件列表看到错误），换一个端口即可。

## 7. 安全说明

- **密码存储**：自动生成/自定义密码以明文保存在当前用户的 `.dsh-lan-access.json` 中（仅本机用户可读）；请勿把该文件分享给他人。
- **明文 HTTP**：局域网内传输为 HTTP，会话 Cookie 理论上可被同一网络中的攻击者窃听。请只在可信网络使用，或通过系统防火墙限制来源 IP；如需公网暴露，建议另行配置 HTTPS 反向代理。
- **令牌不外泄**：LAN 端口不再接受 `?token=` 链接，访问必须经过密码；本机面板也需密码登录。
- **会话吊销**：修改/重置密码会让旧会话立即失效；已登录设备的浏览器需要重新输入新密码。
- **限速**：密码错误 1 分钟内满 5 次将锁定 1 分钟（登录与改密共用该限制）。

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| 面板提示「密码错误」 | 确认使用当前密码；忘记密码可在本机 `.dsh-lan-access.json` 中查看，或在插件配置中设置新的 `password` 字段 |
| 其他设备打不开 | ① 确认在同一局域网；② 检查是否选对接口地址；③ 放行防火墙 8848 端口；④ 确认插件已启用、端口未被占用 |
| 打开后仍是登录页 | 会话已过期或被密码修改吊销，输入新密码即可 |
| 面板地址 404 | 面板端口随 DSH 网页端口变化，请使用当前端口；且需先启用插件 |
| 修改密码后其他设备掉线 | 这是预期行为：旧会话被吊销，重新输入新密码即可 |
| 改了端口不生效 | 监听端口在插件加载时绑定，修改配置后需重启 DeepSeek Harness |

## 10. 已验证范围

- 局域网端口登录、认证后访问网页、`/api` 调用、WebSocket 升级；
- 令牌链接在 LAN 端口被禁用；
- 自定义密码 / 随机重置、长度与确认校验；
- 密码修改后旧页面 / API / WebSocket 会话全部失效；
- 高频异常连接（客户端强制重置、畸形请求、并发旧会话、上传中断）下 Host 进程稳定；
- 插件禁用时端口正确释放、启用后可重新绑定。

**未覆盖**：真实手机 / 另一台电脑的最终连通性（受防火墙与网络环境影响，需按 5.5 实测一次）；HTTPS/TLS（当前为明文 HTTP）。
